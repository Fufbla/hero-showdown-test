START ON YOUR MAC (PYTHON 3 IS ALREADY THE ONLY REQUIREMENT)
1. Extract this ZIP into a NEW folder.
2. For the combined Versus test, open START-PLAYABLE-VILLAINS.command.
3. For the Scorpion boss test, open START-SCORPION-TEST.command.
4. If a launcher does not open, open Terminal in this extracted folder and run:
   Versus:   python3 tools/serve-playable-villains.py
   Scorpion: python3 dist/start-scorpion-test.py
5. Keep the Terminal/server window open while playing. Ctrl+C stops that server.
