HERO SHOWDOWN — LIGHTENING SPREE COMBINED MANUAL UPDATE
October 26, 2026

This package includes Lightening Spree, Atomdust, Venomis & Thornbear,
Sonic Tusk, Styrodog, Dr. Styro, Wastelander, and the saved Supergirls
animation work. Use this ZIP in place of the earlier animation-update ZIPs.

INSTALL WHEN YOU ARE HOME
1. Extract the ZIP.
2. Copy the CONTENTS of GAME-FILES into your existing game folder, beside
   index.html. Keep the assets/animation folder structure. Replace matching
   files and keep all other existing game files.
3. Upload the files yourself, then reload without old cached files.

There are 56 game files: 46 production files and ten optional review files
for Styrodog, Sonic Tusk, Venomis & Thornbear, Atomdust, and Lightening Spree.
README.txt and DEVELOPMENT contain notes and checks for reference.

LIGHTENING SPREE
Sixteen new crystal-character drawings provide planted idle breathing,
beam and spark preparation, release and recovery, reappearance, guard,
and separate light/heavy reactions. Release palms are registered to the
original beam origins in either direction. He never walks; his existing
two-second invisible relocation remains unchanged.

The original beam warning lines, collision shapes, damage, blocking,
five-ray fan, phase-three second volley, cooldowns and shatter defeat remain.
The original artwork and portrait are preserved. If the new sheet cannot
load, the original animation is used automatically.

PLAYTEST
Open lightening-spree-review.html through your normal game server/site.
Choose Summy, Sadie, or Vee, then Practice or Fight Lightening Spree.
Move buttons, quarter speed, and Face right help inspect each sequence.
Hold release freezes a move preview once a beam fires; uncheck it to
continue. Starting Practice or Fight clears that hold. Fight uses normal
health and damage. Original Lightening Spree compares the previous art.

Normal play opens through index.html or hero-showdown.html. Story Mode
remains available. The separate playable-villains competitive branch is
not included. The owner handles game uploads and publication personally.
