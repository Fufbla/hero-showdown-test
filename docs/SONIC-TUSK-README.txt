HERO SHOWDOWN — SONIC TUSK COMBINED MANUAL UPDATE
October 26, 2026

Use this ZIP in place of the earlier Dr. Styro / Styrodog update ZIPs.
It includes their saved work plus the Sonic Tusk animation pass. It is a
changed-files update for your existing game, not a standalone full game.

INSTALL WHEN YOU ARE HOME
1. Extract the ZIP.
2. Copy the CONTENTS of GAME-FILES into the existing game folder, beside
   index.html. Keep the assets/animation folder structure. Replace files
   with matching names and keep all other existing game files.
3. Upload those files yourself. The observed GitHub main layout has
   index.html and hero-showdown.html at the repository root.
4. Reload without old cached files after replacing the game files.

37 game files are included: 33 production files and four optional review
files (the Styrodog and Sonic Tusk review HTML pages and their scripts).
README.txt and DEVELOPMENT contain notes and source checks, not game uploads.
Each individual game file is below 3.2 MB.

SONIC TUSK
The game uses 32 new drawings: eight walk poses, four idle poses, distinct
light/heavy hit reactions and recovery, six sonic-pulse poses, six bass-stomp
poses, and four horn-blast poses. Three transparent atlases hold the selected
drawings; the corrected step quartet replaces four unused presence poses.
Pulse release follows projectile creation. The stomp contacts the floor
with its bass waves. The horn blast stays in an emitting pose while the
original growing cone can hurt a hero. Damage, collision rules, difficulty
timing, sonic effects, and the original collapse are preserved.

PLAYTEST
Open sonic-tusk-review.html through your normal game server/site after
applying the files. Choose Summy, Sadie, or Vee, then Practice or Fight
Sonic Tusk. Move buttons, quarter speed, and Face right help inspect each
action. Original Sonic Tusk compares the original animation.
Normal play still opens through index.html or hero-showdown.html.
