HERO SHOWDOWN — STYRODOG + DR. STYRO MANUAL UPDATE
Prepared October 26, 2026

This ZIP includes the saved Dr. Styro update and the new Styrodog animation
pass. It replaces the earlier Dr. Styro ZIP for installation purposes.
It contains changed files only; it is not a standalone copy of the game.

INSTALL WHEN YOU ARE HOME
1. Extract the ZIP.
2. Copy the CONTENTS of GAME-FILES into your existing game folder, beside
   its current index.html. Keep the assets/animation subfolder structure.
   Replace files with the same names; keep the rest of the existing game.
3. Upload those game files yourself. The existing GitHub main layout puts
   index.html and hero-showdown.html at the repository root.
4. Reload the game without its old cached files after you upload.

All 29 game files are included. Two are optional review files:
  styrodog-review.html
  assets/animation/styrodog-review.js
The other 27 are the combined production update.
README.txt and DEVELOPMENT are notes/source checks, not game uploads.

WHAT CHANGED
Styrodog has 32 new drawings: an eight-pose walk, four idle poses, light and
heavy hit reactions, recovery, and distinct claw, slam, and roar sequences.
The claw contact pose follows its damage timing; the slam lands with its
shockwaves; the roar follows its three foam-shot volleys. Existing combat
rules, damage, moves, and the collapse/defeat sequence are preserved.
The approved Supergirls, Wastelander, and Dr. Styro animation work is included.

PLAYTEST
Open styrodog-review.html through your normal game server/site after applying
the files. Choose a hero, then Practice or Fight Styrodog. The move buttons
and quarter-speed option help review each motion. Original Styrodog switches
to the old artwork for comparison. The normal index.html remains the game.
This work does not add playable villains from the separate versus branch.

WORKFLOW
