# Vice Costume test integration

Vice Costume is available only in the existing isolated `0000000000` test
profile. The approved design uses black shorts, a white tank with neon-pink
Vice lettering, a backward black cap, and black shades. It is unisex and costs
700 coins. Purchases do not automatically equip it.

The permanent ownership reference is `vice-costume.fullbody`. The test wrapper
adds it to the existing 30-costume collection, retaining Fancy Costume and all
earlier purchases. The existing test wallet and its one-time 10,000-coin grant
are unchanged; entering this release never replenishes spent coins.

Only `test-only/four-powers/build.cjs` and its Node test loader map the shared
catalog, renderer and wardrobe policy to these wrappers. Each wrapper also
requires the exact isolated gameplay or local-co-op route and
`testAccount=0000000000`. A normal game URL, another code or a missing code
retains the unchanged production collection. Base imports use `?four-base=1`
to avoid circular remapping.

The test compiler copies the whole `vice/assets` directory, including the
separate cap, glasses and lettering overlays, into
`four-powers-test/vice/assets`. Hashed bundle entry names are generated by the
existing build so updated costume dependencies produce a new test launcher.
The ordinary production catalog and active cloud save service do not receive
Vice Costume or any wardrobe-policy change.

Integration responsibilities:

- `catalog.mjs`, `outfit-policy.mjs`, `scope.mjs` and `definitions.mjs` provide
  the isolated store, ownership rules and route checks.
- `engine.mjs` and `head.mjs` render the approved body and the player's existing
  face with the costume's cap and shades.
- `assets/` contains approved artwork and measured sprite registration.
- `tests/` checks purchase, equip, persistence, scope, artwork fit and retained
  existing behavior before publishing the test build.
